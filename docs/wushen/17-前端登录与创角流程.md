## 17.2 一次完整登录的时序图

```
打开页面
  │
  ├─ document.cookie 有 p ?
  │    否 → 显示 #login_panel
  │    是 → 直接进入第 3 步（免登录）
  │
  ▼ 用户输入账号密码 → POST /api/user/login
HTTP 响应 {code:1, p:"<票据>", u:"<sessionId>"}
  │   服务端同时 Set-Cookie: u=...; p=...
  ▼
GET /api/game/servers → [{id,name,ip,port,...}]
  │   渲染 ul.server-list
  ▼ 用户点选服务器
  │   SetCookie("s", index)
  ▼
new WebSocket("ws://127.0.0.1:31300")
  │
  ├─ onopen → send("<u> <p>")
  │
  ▼ 服务端解密票据 → 鉴权通过
WS ← {type:'roles', roles:[{name,title,id}]}
  │   渲染 ul.role-list
  ▼ 用户点角色
WS → "login <roleId>"
  │
  ├─ 服务端查库、loadData、do_login、进入房间
  │
WS ← {type:"login", id, level, setting}     ← 切主界面
WS ← {type:"room", ...}                     ← 房间
WS ← {type:"exits", items:{...}}            ← 出口
WS ← {type:"items", items:[...]}            ← 房间物件
WS ← {type:"map", path, map:[...]}          ← 地图
WS ← 一堆纯文本消息（欢迎语等）
  │
  ▼ 进入游戏
```

### 随机四维（roles.js:54-73）

- 四个属性各在 **15-30** 之间
- **总和必须等于 80**（服务端 `world/cmd/comm/createrole.js:40` 校验："属性之和必须等于80"）
- 实现：先各取 15（共 60），再把剩余 20 随机分配

### 提交

```js
SendCommand("createrole {name} {gender} {str} {con} {dex} {int}");
```

| 校验 | 错误信息 |
|---|---|
| 已登录 | 请刷新页面重新操作 |
| 参数缺失 | 注册信息错误 |
| 姓名 2-5 汉字 | 姓名需要是2-5个汉字 |
| 禁用名 | 你不能用这个名字 |
| 重名 | 这个名字已经有人用了 |
| 力量/根骨/身法/悟性 15-30 | XX属性需要在15-30之间 |
| **四维之和 = 80** | 属性之和必须等于80 |
| 写库失败 | 创建角色失败 |

```js
async function Request(url, data, callBack, method) {
    const resp = await fetch(url, {
        method: method || 'POST',
        credentials: 'include',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify(data)
    });
    const result = await resp.json();
    callBack && callBack(result);        // ⚠️ callback 风格，调用方都不 await
}
```

## 17.8 复刻建议

1. ✅ **"HTTP 拿凭证 → Cookie → WebSocket 首包携带凭证"** 这套 SSO 流程简洁有效，值得抄（但凭证内容要改，见第 03 册）。
2. ✅ **`hide2show` 统一面板切换动画**让登录流程体验连贯，值得抄。
3. ✅ **免登录（Cookie 判活）**值得抄：直接跳过登录页进入选服。
4. ❌ **callback 风格必须改 Promise**：当前 `Request` 是 async 但调用方不 await，错误无法冒泡。
5. ❌ **四维之和必须等于 80 的硬约束**要在前端就做实时校验（当前只在提交后由服务端报错返回，体验差）。
6. ⚠️ 建议增加**连接状态机**（`connecting / connected / reconnecting / offline`），当前只有 `IsConnecting` 一个布尔值。
