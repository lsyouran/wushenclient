## 一、项目速览

| 项 | 值 |
|---|---|
| 技术栈 | Node.js（>= 24.10）+ 原生 JS（CommonJS）+ Vite 8 + jQuery 4 |
| 服务端 | 自研 WebSocket 服务器（`net` 模块手写 RFC6455）+ Express 5 Web 服务 |
| 数据库 | SQLite（`better-sqlite3`） |
| 前端 | 无框架的原生 ES Module + jQuery，**无虚拟 DOM、无模板引擎** |
| 代码规模 | `os/` 9,716 行 · `src/` 11,261 行 · `world/` 39,086 行（926 文件）· `api/` 1,163 行 |
| 端口 | Web `:8088`（`.env` 可配）、游戏 WS `:31300`、GM 代理目标 `:8090` |
