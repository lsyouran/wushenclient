## 10.1 ROOM（os/room/room.js，692 行）

`ROOM.inherits(ITEM)`（`room.js:8`），房间本身就是一个容量 50 的容器。

**字段**：`name`、`desc`、`items[]`（**房间里所有东西：玩家、NPC、掉落物都在这一个数组里**）、`parent`（所属 AREA）、`exits{}`、`hidden_items[]`、`long_name`、`json`/`commands_json`/`room_exits_json`（三级缓存）、`owner`（副本归属）、`copy_rooms{}`、`shadow_rooms[]`、`temp`。

## 10.2 出口（exits）的表示

```js
this.exits = { north: "yz/wumiao", east: ["yz/dajie"], ... }   // room.js:250-263
```

- **值是目标房间的 path 字符串**（不是对象引用），取值时 `ROOM.Get(this.exits[dir])` 现查（`room.js:283`）
- 方向 key 集合由 `world/cmd/action/go.js:50-58` 的 `doors[]` **在命令层**定义，共 20 个：
  `west/north/south/east/northwest/southwest/northeast/southeast/down/up/westdown/eastdown/northdown/southdown/westup/eastup/northup/southup/enter/out`
  短写：`s/n/w/e/se/sw/nw/ne/d/u/sd/ed/nd/wd/su/eu/wu/nu`
- 实测使用频次（`world/map/` 统计）：`north`92 `south`91 `east`86 `west`85 `up/down`各 20 `out`6 `enter`3 + 复合方向

| 方法 | 行 | 说明 |
|---|---|---|
| `add_exit(dir, rm)` / `remove_exit(dir)` | `:254/:259` | 会调 `exits_changed()` 清缓存并重发出口包 |
| `exitsto_roomjson()` | `:275` | → `{type:"exits", items:{dir: roomName}}`，缓存在 `room_exits_json` |

## 10.3 AREA（区域）

| 侧 | 代码 | 说明 |
|---|---|---|
| 房间找区域 | `getAreaByPath(path)` `room.js:602-609` | 取 path 的最后一级目录（`yz/wumiao` → `yz/`），遍历 `WORLD.AREAS` 比对 `area.room_path` |
| 注册 | `ROOM.initBaseRoom` `room.js:407-431` | 写 `WORLD.ROOMS[file]`；`parent=area`；非副本 push 进 `WORLD.RUN_ROOMS`；塞进 `area.rooms[]` |
| 区域注册 | `AREA.create` `area.js:16` | push 进 `WORLD.AREAS`；若有 `family` 则 `FAMILIES[family].area = this` |

**区域字段**（`area.js:1-14`）：`rooms[]`、`map[]`（地图数据）、`name`、`is_area`、`first`(入口房 path)、`is_show`、`is_copy`(副本区)、`expend`、`is_multi`、`index`、`exp/pot`。

## 10.4 四种房间形态

| 形态 | 判定 | 创建 |
|---|---|---|
| 普通房 | `!parent.is_copy` | `initBaseRoom` |
| 副本房 | `is_copy() = parent.is_copy`；`is_fb() = parent.is_copy && !parent.not_fb` | `create_copy(id,diff)`（`room.js:536`）→ `create_by_area` 复制整个 area，`copy_rooms[id]` 索引，`owner=id` |
| 投影房（分流） | `is_shadow` | `create_shadow()`（`room.js:562`）：`is_full()` 时造克隆房分流，`shadow_rooms[]` 复用不销毁 |
| 门派区域 | `FAMILY_AREA` | 空壳 |

## 10.5 移动全流程（★ 最核心的链路）

```
客户端发 "go north"
  ↓ os/net-ws.js:130 onReceive → os/ws.js:24 → WORLD.request
  ↓ user.command (character.js:136) → do_command (character.js:156)
  ↓ WORLD.COMMANDS["go"] → world/cmd/action/go.js:5 enter(me, dir)
      ├─ OUTER_DOORS[dir] 归一化方向名
      ├─ cur_room.exits[dir] → rmPath → ROOM.Get(rmPath)
      ├─ me.fight_type>0 → me.do_escape()（chara_move.js:105）
      ├─ 副本/通缉等规则校验
      └─ me.moveto(next_room, outMsg, inMsg, dir)
  ↓ CHARACTER.moveto (chara_move.js:3)
      ├─ 同 area 内取 query_copy(owner)，跨 area 取 query_copy2(user)
      ├─ next_room.is_full() → next_room.create_shadow()
      ├─ cur_room.do_leave(obj, dir, leave_msg)    (room.js:11)
      │    ├─ area.on_leave / room.on_leave 可否决
      │    └─ room.item_changed(obj, false, msg, dir)
      ├─ next_room.do_enter(obj, true, in_msg)     (room.js:20)
      │    ├─ obj.is_player → send(to_json()) + send_exits() + send(items_to_json())
      │    ├─ room.item_changed(obj, true, in_msg) → 广播 itemadd + 触发房内 NPC 的 on_enter
      │    └─ room.on_enter
      ├─ me.notify_follower(dir)  (chara_move.js:77) → 随从逐个 moveto
      └─ 跨区域 → cur_room.parent.on_leaved(me)
```

### `item_changed` —— 房间内容变更的唯一枢纽（room.js:29-72）

一次遍历 `items[]`，给所有 `is_player` 发 `itemadd`/`itemremove` JSON、发移动消息，并回调房内其它 NPC 的 `on_enter`/`on_leave`（**返回 `false` 可否决这次变更**）。

## 10.6 房间脚本范式（world/map/，298 个文件）

### 示例 A：新手训练室（脚本化引导）

```js
// world/map/new/new1.js
this.inherits(ROOM);
this.name = "训练室"
this.desc = "这是一间空荡荡的训练室...房子中间有个桌子，几张<cmd cmd='look yizi'><hig>椅子</hig></cmd>。";
this.exits = { "east": "new/new2" };
this.set_npc("new/daoshi");
this.no_fight = true;
this.on_enter = function (me) {
    if (me.query_temp("new") == 1) {
        me.notify("指引者双手抱拳...");
        me.send_commands('guide_over', '<blk>直接闯荡江湖</blk>', 'guid_start', '<hig>我需要指引</hig>');
        this.items[0].add_action("guid", "我需要指引", on_guide);
    }
}
this.add_action("guid_start", null, function (me) { ... });
this.set_item("yizi", "椅子", "这是一张椅子，可以坐。", [[
    "zuo2", "坐下去", function (me) { me.notify("你拉开一张椅子坐了上去。"); }
]]);
this.on_leave = function (me, dir) {
    if (!me.is_player) return true;
    var lv = me.query_temp("new");
    if (lv && lv < 4) return me.notify_fail("你先听完课再乱跑。");
    if (dir != "east") return me.notify_fail("你要去东面的训练室找指引者。");
}
```

### 示例 B：客栈客房（私房 + 状态加成 + 心跳回收）

```js
// world/map/kezhan/fang1.js
this.inherits(ROOM);
this.name = "人字号客房";
this.exits = { "down": "yz/kedian" };
this.max_item_count = 1;
this.is_shadow = true;
this.on_enter = function (me) {
    if (check_moveout(me)) me.add_status({
        id:"room", duration:0, name:"人字号",
        desc:"你在客栈人字号客房，安安静静的是个练功的好地方",
        prop:{ study_per:10, lianxi_per:10, dazuo_per:10 }
    });
}
this.on_leave = function (me) { me.remove_status("room"); }
this.on_heart_beat = function () {
    for (let item of this.items) if (item.hp > 0) return check_moveout(item);
}
function check_moveout(me) {
    if (!me.query_temp("kezhan")) {
        me.moveto("yz/kedian", null, me.name + "走了下来。");
        me.send_room("店小二对$N说道：这位客官，你需要付钱才可以继续住店。");
        return false;
    }
    return true;
}
```

## 10.9 复刻建议

1. ✅ **"房间即容器"是本项目最漂亮的设计**：`CHARACTER.inherits(ITEM)` + `ROOM.inherits(ITEM)`，让"玩家在房间里"和"剑在地上"共享同一套 `item_changed` 广播逻辑。强烈建议保留。
2. ✅ **出口用 path 字符串而非对象引用**：避免循环引用、便于热更新（改房间不用改邻居）。保留。
3. ✅ **投影房（shadow room）分流**：房间满员自动克隆分流，解决"客栈只有一个房间"的问题。值得抄。
4. ❌ `getAreaByPath` 靠字符串前缀匹配 + 线性遍历 → 改 Map 索引。
5. ❌ `WORLD.RUN_ROOMS` 全量心跳 → 改为"只心跳有玩家的房间"（脏标记 + 活跃集合）。
6. ⚠️ 三级 JSON 缓存（`json`/`commands_json`/`room_exits_json`）必须记得在 `add_exit`/改描述时清，否则热更新后客户端拿到旧数据。建议改为版本号机制。
