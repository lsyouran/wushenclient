## 9.3 OBJ — 基础物件

### 9.3.1 字段（obj.js:2-9）

`unit`(量词"个")、`path`、`count`、`combined`(可堆叠)、`grade`(品阶 0-6)、`otype`(客户端分类)。

派生：`transable`(可否交易)、`value`、`color_name`（由 `grade_color[grade]` 生成，`obj.js:170/177`）、`is_money`/`is_equipment`/`is_container`、`drop_list`、`temp`、`is_locked`、`distime`(使用冷却)。

### 9.3.2 工厂（obj.js:153-169）

```
OBJ.CREATE(otype, count)
  └─ WORLD.OBJ_STROE.get(otype) 命中？
       否 → BASE.CREATE(__PATH.OBJ, otype)（脚本内 create() 会写回 STROE）
            未定义则 throw '没有物品xxx的定义。'
     Object.create(base) → create_id() → on_clone() → count>1 则设 count
```

### 9.3.3 关键方法

| 方法 | 行 | 说明 |
|---|---|---|
| `save_db(str)` | `:120` | 输出 `["path","id",count,(1\|temp)]` |
| `load_db(data)` | `:130` | `data[3]===1`→`is_locked`；object→`temp` |
| `combine(obj)` / `uncombine(sp)` | `:80/:48` | 堆叠合并/拆分，`combineTemp` 对数值取 max |
| `clone()` | `:57` | `OBJ.CREATE(this.path)` + 浅拷贝 temp |
| `create_by_odds(args)` ★ | `:204` | **掉落表 roll**：`{obj, fall_obj, odds, count, min, max}`；`Math.random()*10000 < odds` 取 obj 否则 fall_obj |
| `on_load(me)` / `on_clone()` | `:146/:150` | 生命周期钩子 |

### 9.3.4 客户端序列化（`world/extends/item/obj.js`）

```js
OBJ.prototype.format_to_pack = function () {
    return `["${this.color_name}","${this.id}",${this.count},${this.grade},"${this.unit}",
             ${this.transable ? this.value : 0},${this.is_equipment ? 1 : 0},${this.on_use ? 1 : 0},
             ${this.on_study ? 1 : 0},${this.on_open ? 1 : 0},${this.combine_count > 0 ? this.combine_count : 0},
             ${this.is_locked ? 1 : 0},${this.otype}]`;
}
```

## 9.5 CONTAINER / CORPSE / MONEY

| 类 | 行 | 要点 |
|---|---|---|
| `CONTAINER` | `container.js:2` | `set_items(...)` 用 `OBJ.clone_to` 灌初始物品；`CONTAINER.CREATE(name,desc,lv,odds)`（`:61`）用 `sp/box#lv` 模板 + `OBJ.create_by_odds(odds)` 造宝箱 |
| `CORPSE` | `corpse.js:2` | `init(player, iskeep)`：命名 `"<name>的尸体"`、`items = player.query_drop()`（按掉落表 roll）、非副本 `call_out(disappear, 60000)`；副本里按队伍生成 `no_drops` 白名单 |
| `MONEY` | `money.js:2` | 被 `push_item`/`clone_to` 特判，**不进 `items[]`**，直接 `this.money += value*count` |

## 9.9 复刻建议

1. ✅ **品阶（grade）+ 精炼（level）+ 镶嵌（st_prop）+ 套装（group_prop）** 这套四层装备强化设计完整且实用，值得直接抄结构。
2. ✅ `create_by_odds` 掉落表（含 `odds`/`min`/`max`/`fall_obj` 兜底）设计简洁，值得抄。
3. ❌ `find_obj_byid` 线性扫描 → 改 Map 索引。
4. ❌ `format_to_pack` 返回**数组**而非对象（13 个下标靠注释记忆）→ 改为具名对象，配合 TypeScript 类型。
5. ⚠️ 金钱作为 `money` 字段而非物品对象（MONEY 类被特判），这个设计在战斗奖励/商店扣款时方便，但在"背包里显示金币"时会有特例分支——建议一开始就明确"货币是独立字段还是物品"。
