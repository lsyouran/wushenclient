## 19.3 图标：只用 Glyphicons

| 资源 | 使用 | 证据 |
|---|---|---|
| **`glyphicons-halflings-regular.{eot,ttf,woff,woff2}`** | ✅ **在用** | `global.css:600-604 @font-face` + `:606-616 .glyphicon` 基类 + **55 个 `.glyphicon-*:before`**（`:618-839`，逐个手写 `content:"\eXXX"`） |
| **`fa-solid-900.woff2`** | ❌ **完全未使用** | 全库 `grep "fa-\|fa-solid"` 零命中，无对应 `@font-face` |

### 两种用法

```html
<!-- ① HTML 模板里直接写 class -->
<span class="glyphicon glyphicon-user tool-icon"></span>
<span class="dialog-close glyphicon glyphicon-remove-circle"></span>

<!-- ② JS 运行时替换（dialog 标题图标） -->
Dialog.icon(css)  → this.iconElement.attr("class", "dialog-icon glyphicon glyphicon-" + css);
```

`Dialog.icon()` 调用处：`pack "briefcase"` / `skills "book"` / `tasks "exclamation-sign"` / `shop "shopping-cart"` / `events "dashboard"` / `jh "home"` / `team "list"` / `relation "heart"` / `party "flag"` / `score "user"` / `setting "cog"` / `channel "comment"`。

另有两处 CSS content 形式图标：
- `.bottom-bar>.br-tool::before { content:"\e234"; font-family:'Glyphicons Halflings'; }`
- `.obj-list>.lock:before { content:"\e033"; }`（背包锁定标记）

## 19.4 响应式：**有，但很粗**

只有 **2 个 media query 块**，全在 `global.css:47-98`：

| 断点 | 内容 | 行 |
|---|---|---|
| `@media(min-width: 768px)` | **桌面端把 body 限制为 768px 居中**（模拟手机宽度） | 47-58 |
| `@media(max-width: 480px)` | 底部 Tab 缩到 `4em`、数量 chips 缩小、confirm 按钮 `3em`、`.fb-left` `8em`、排行榜 Tab 与仓库类型 Tab 改**竖排**(`writing-mode: vertical-rl`) | 60-98 |

JS 层的软适配：`Util.isMobile`（`util.js:4`，UA 判断）用于

| 位置 | 行为 |
|---|---|
| `message.js:17-21` | touch vs wheel 事件选择 |
| `dialog/keys.js:115` | 移动端不启用键盘快捷键 |
| `dialog/setting.js:13` | 移动端移除「快捷键」Tab |

> **结论：采用"定宽 768px 居中 + 移动端微调"策略，本质是「手机版做桌面版」的伪响应式**，配合 `index.html` 的 `user-scalable=no`。

## 19.6 内联 CSS 注入机制

```js
// src/dialog/base.js:130-134
injectStyle: function (css) {
    const style = document.createElement("style");
    style.innerHTML = css;
    document.head.appendChild(style);
}
```

注入点：`packet.js:483`（`packet_css` + `list_css`）、`skills.js:438`、`message.js:273`、`tasks.js:3`、`events.js:4`、`shop.js:173`、`paimai.js:3`、`jh.js:390`、`party.js`、`setting.js`、`stats.js`。

> ⚠️ 多数无重复检测（只有 `packet.js:18` 用 `if(!this.created)` 挡了一下），反复开关面板会重复注入 `<style>`。

## 19.7 复刻建议

1. ✅ **ANSI 16 色 + 终端绿**的复古风格与 MUD 类型高度契合，值得保留。建议直接把色表抽成 CSS 变量：
```css
:root { --c-hig:#00FF00; --c-hir:#FF0000; ... }
hig { color: var(--c-hig); }
```
2. ✅ **自定义标签着色**（`<hig>` 而非 `<span class="hig">`）让服务端文案极简洁，值得保留。但要加**标签白名单 + 转义**，否则是 XSS 入口。
3. ❌ **`fa-solid-900.woff2` 应删除**（43KB 死资源）。
4. ❌ **不要用运行时 `injectStyle`**：改构建期提取，或用 CSS Modules / `<style scoped>`。
5. ❌ **`publicDir: false`** 让资源管理变麻烦，建议改为默认 `public/` + 显式 import 双轨。
6. ⚠️ **响应式策略要重新设计**：当前"768px 定宽居中"在平板上会留下大片空白。建议改为真正的移动端优先 + 平板/桌面双栏布局。
7. ⚠️ 建议引入 CSS 变量做主题（当前颜色硬编码在 22 处 CSS 规则里），便于做"暗色/亮色/复古"多主题。
